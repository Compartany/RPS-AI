# RPS-Duel · 石头剪刀布 自适应 AI

一个纯前端的「石头剪刀布」对战程序：电脑会记录你的出招习惯，用多种统计标准预测你的下一招，并不断按应验率修正各标准的权重。

## 运行

无需构建，直接用浏览器打开 `index.html` 即可（双击也行）。

## 玩法

- 上方是电脑，下方是你的三个出招按钮（键盘 `1` / `2` / `3` 同效）。
- 每局开始电脑已先选好招，你点击后同时揭示并判定胜负。
- 上一轮回顾：电脑出招格**右侧的小格**（1/4 大小）显示它上一局出的招；你上一局出的那个按钮**右下角**会标出「赢 / 平 / 输」（绿 / 灰 / 红）。
- 顶部记分板展示**电脑胜率 / 平局率 / 你的胜率**，以及 AI 对你下一招的预测命中率。
- 点「显示分析面板」可展开右侧表格：每个标准的当前依据、历史计数、预测、应验率与权重。
- 底部「对局记录」：走势条（绿=你胜 / 红=电脑胜 / 灰=平）+ 最近 40 局的出招缩略，悬停看详情。

## AI 策略

电脑把每个「标准」当成一个独立专家，各自统计「在这种局面下你会出什么」：

| 标准 | 含义 |
| --- | --- |
| 整体频率 | 你的总体出招偏好 |
| 我方前 N 招 | 你自己最近连续 N 招之后的下一招 |
| 对手前 N 招 | 电脑最近连续 N 招之后你的应对 |

- N 可在界面设置（1~6）。从 1 到 N 的每个阶数都是**独立标准**。
- 每个标准内部按具体键值（如 `✊→✌️`）分别计数。
- 预测时用拉普拉斯平滑得到各标准的人类出招分布，再按 `(基础权重 + 应验率) × 样本置信度` 加权求和，得到综合分布。
- 电脑出招 = 能击败「综合分布中概率最高那一招」的招。
- **探索扰动**：当预测不明确或历史应验率低时，会以一定概率随机出招，避免被人类反向针对。

### 可调参数（面板底部「策略参数」）

| 参数 | 作用 |
| --- | --- |
| 平滑系数 α | 拉普拉斯平滑强度。α 越小越激进地相信少量样本 |
| 探索强度 | 探索抗动的倍率，0 = 完全利用（最容易被针对性套路） |
| 启用探索扰动 | 总开关，关掉后 AI 永远按预测最优出招 |

改动 α 会回放全部历史重新评估各标准的应验率。
